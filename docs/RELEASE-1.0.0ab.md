# AILSA SubSwitch 1.0.0(ab)

- Gemini 4 Carbon now shows token usage and equivalent API cost for OpenCodex Antigravity routes and the native Antigravity app. Dashboard and share reports use one model name; an identical provider response recorded by both sources is counted once.
- Value all Carbon usage, including November history, at Google's December 1, 2026 list prices: $4.00 per million uncached input tokens, $0.20 per million implicit cache reads and $20.00 per million output tokens. This reference deliberately excludes the November promotion. Output includes thinking tokens. Confirmed Priority requests use Google's published 1.8× rates.
- Preserve Antigravity's reported quota scope: shared Gemini windows stay shared. Carbon-specific window IDs are labeled when present. Token costs are API-equivalent estimates, not subscription charges.
