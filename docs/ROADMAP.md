# Roadmap

This is a set of priorities, not a promised schedule.

## 1.0.0

- Clear English documentation, local build instructions and upstream attribution.
- A tested Apple Silicon archive with checksums and explicit signing status.
- Account switching, quota visibility and recorded-usage analysis.
- Manual updates. No OTA dependency in the shipped application.

## Next

- Fix issues reported against real provider sessions and add sanitized fixtures.
- Improve missing/stale-data explanations and keyboard/accessibility behavior.
- Complete translation coverage for newer controls.
- Validate widgets and alternative build paths on clean macOS installations.
- Maintain model-family mappings and auditable price sources.

## Later

- Stable Developer ID signing and notarization.
- A verified in-app update path after the signing and release process is stable.
- Additional providers only when their authentication and usage sources can be
  supported without inventing data or weakening credential protection.
